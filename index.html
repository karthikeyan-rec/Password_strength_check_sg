About SecureGuard

Password security education and best practices

🔐

How Strength is Calculated

SecureGuard uses a multi-factor scoring system that evaluates:

  • Length: Longer passwords exponentially increase combinations.
  • Complexity: Mix of uppercase, lowercase, numbers and symbols widens the character pool.
  • Entropy: log2(charset_size ^ length) — measures true randomness in bits.
  • Pattern Detection: Detects repeated chars, sequences, and common words.
  • Breach Lists: Checks against the most commonly breached passwords.
📚

Cryptography Basics

  • Hashing: One-way transformation (SHA-256, bcrypt) — irreversible by design.
  • Salting: A random value added before hashing to prevent rainbow table attacks.
  • Key Stretching: bcrypt/Argon2 intentionally slow hashing to defeat brute force.
  • MFA: Even a weak password is safer with multi-factor authentication.
🛡️

Best Practices

  • Use a password manager (Bitwarden, 1Password).
  • Never reuse passwords across services.
  • Enable 2FA/MFA wherever possible.
  • Use passphrases — e.g., "correct-horse-battery-staple".
  • Change passwords after known data breaches.
⚡

Attack Methods

  • Brute Force: Tries every possible combination.
  • Dictionary Attack: Uses lists of common words and passwords.
  • Rainbow Table: Pre-computed hash lookups (defeated by salting).
  • Credential Stuffing: Uses breached username/password pairs.
  • Phishing: Tricks users into revealing their password.
